☁ 云同步设置

选一种云存储：电脑 / 手机 / 平板填写相同账号信息即可共享数据。不联网时用 ⬇ 备份 / ⬆ 恢复 经百度网盘 / WPS 云文档迁移。

怎么用「百度网盘 / WPS」在手机·平板·电脑间同步？ ▸
● 百度网盘 ● WPS 云文档
  1. 电脑上正常使用工作台，改完重要内容后点底部「⬇ 备份」，会下载一个 小鱼工作台_备份_日期.json。
  2. 打开百度网盘（电脑客户端或网页版），新建一个文件夹如「工作台备份」，把刚下载的 JSON 和 小鱼工作台.html（代码本体）都传进去。
  3. 手机/平板装 百度网盘 App，登录同一账号，进入「工作台备份」文件夹，把这两个文件都下载到本地。
  4. 手机用浏览器（Safari / Chrome）打开 小鱼工作台.html → 点底部「⬆ 恢复」→ 选中下载的 JSON → 数据就过来了 ✅
💡 小技巧：手机微信「文件传输助手」发这个 HTML 也能秒传到手机；百度网盘的「同步空间」还能让电脑端自动上传备份文件，换设备只差一步下载恢复。
  1. 电脑上点底部「⬇ 备份」得到 JSON 备份文件。
  2. 打开 WPS / 金山文档，把 JSON 和 小鱼工作台.html 都存入云文档（建议同一文件夹）。
  3. 手机装 WPS App，登录同一账号，从云文档把这两个文件下载到本地。
  4. 手机用浏览器打开 HTML → 点「⬆ 恢复」→ 选 JSON → 完成迁移 ✅
💡 想更快？把 小鱼工作台.html 本体也常驻云文档，三端都从云文档取同一份，避免版本不一致。注意：网盘只同步"文件"，数据仍需用 ⬇/⬆ 这一步搬运。
